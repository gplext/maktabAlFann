# Maktaba Al-Fann — Pakistani Art Gallery

An exclusive online gallery selling fine Pakistani art. Story-driven, not
product-driven — every artwork carries its style, technique, and the story of
its maker.

## Run

```bash
pnpm install

# API (port 8080)
DATABASE_URL=... PORT=8080 pnpm --filter @workspace/api-server run dev

# Frontend (any port; proxies /api to the API server)
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/art-gallery run dev
```

Other commands:

- `pnpm run typecheck` — typecheck every package
- `pnpm run build` — typecheck + build every package
- `pnpm --filter @workspace/db run push` — push Drizzle schema changes (dev only)

## Required environment variables

API server: `DATABASE_URL`, `PORT`, `CLERK_SECRET_KEY`, `CLERK_PUBLISHABLE_KEY`,
`SESSION_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ANTHROPIC_API_KEY`
(natural-language artwork search), and — only if object storage is in use —
`DEFAULT_OBJECT_STORAGE_BUCKET_ID`, `PRIVATE_OBJECT_DIR`,
`PUBLIC_OBJECT_SEARCH_PATHS`.

Frontend: `VITE_CLERK_PUBLISHABLE_KEY`, `PORT`, `BASE_PATH`, and optionally
`API_ORIGIN` (defaults to `http://localhost:8080`).

Never commit values for any of these.

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React 19 + Vite, Wouter routing, Framer Motion, TanStack Query
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Auth: Clerk (artists, galleries, collectors) + a separate env-credential
  admin session (`express-session`)
- Validation: Zod (`zod/v4` subpath) and `drizzle-zod`
- Build: esbuild (ESM bundle) for the API, Vite for the frontend
- Fonts: Cinzel (display), Playfair Display (body), Scheherazade New (Arabic)

## Where things live

| Path | Contents |
| --- | --- |
| `lib/db/src/schema/` | Drizzle table definitions — source of truth for the DB |
| `lib/api-zod/src/` | Request/response Zod contracts shared with the API |
| `lib/api-client-react/src/` | React Query hooks the frontend consumes |
| `artifacts/api-server/src/routes/` | Express route handlers |
| `artifacts/art-gallery/src/pages/` | Page components (one ger route) |
| `artifacts/art-gallery/public/images/artworks/` | Artwork images served statically |

## Architecture notes

- `lib/api-zod` is hand-maintained. It was originally generated by Orval from
  an OpenAPI spec that did not survive the Replit export; edit it directly and
  keep `lib/api-client-react` in sync with it.
- Cart identity is a `sessionId` in `localStorage` — no auth required to build a
  collection. Do not add query params to the cart DELETE route; path params only.
- Google Fonts `@import url(...)` MUST be the first line of `index.css`, before
  `@import "tailwindcss"`. PostCSS fails silently otherwise.
- Run `pnpm run typecheck:libs` after adding a file to `lib/db/src/schema/`.
